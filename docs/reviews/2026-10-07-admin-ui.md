# Đồng bộ giao diện Admin — 07/10/2026

## Yêu cầu và nguyên nhân

Người dùng yêu cầu menu Admin cùng màu menu dự án và sửa các lỗi nút sát nhau như ảnh `Khóa / Cấp quyền tạo Tester`. Admin dùng CSS nền trắng riêng; các nút trong ô bảng đứng cạnh nhau mà không có nhóm layout. Tái hiện trên Chrome trước sửa: nền menu `rgb(255,255,255)`, hai nút PM xuống dòng với khoảng cách dọc **0px**, cao 38px ở viewport 942px.

Áp dụng `ui-ux-pro-max` và `ui-styling`: dùng token màu chung, khoảng cách rõ ràng, vùng bấm 44px, focus bàn phím và bố cục co giãn. Đọc hướng dẫn skill; script tra cứu Python không chạy được vì môi trường không có `python`/`py`, dùng checklist trong SKILL.md và bằng chứng trình duyệt. Giữ React JavaScript/CSS hiện có, không thêm thư viện giao diện.

## Thay đổi

- Menu Admin và dự án dùng chung token nền `#147e75`, hover và active. Admin có icon Lucide trang trí, nhãn luôn hiển thị trên mobile, footer S+TMS. Mục đang chọn giữ nền sáng khi hover; focus bàn phím có viền rõ.
- Nhóm thao tác người dùng, thành viên dự án, thiết bị và nút Lưu/Hủy có gap 8px, tự xuống dòng. Các control Admin cao tối thiểu 44px.
- Gom nút trên tiêu đề kho thiết bị; phân trang tự xuống dòng; tên thành viên dài và bộ chọn vai trò không đẩy form ra ngoài. Checkbox thiết bị nằm cùng nhãn, danh sách bỏ chọn có khoảng cách.
- Bảng rộng cuộn trong vùng riêng; không thay đổi API, quyền, trạng thái, schema hoặc dữ liệu nghiệp vụ.
