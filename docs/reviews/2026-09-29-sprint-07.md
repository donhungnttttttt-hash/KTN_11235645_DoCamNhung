## Review code và bảo mật

- Project lock lấy trước read/write có cạnh tranh; version guard trên bug/request/run, assignment được kiểm tra lại khi submit; transaction FULL_CASE/verification/history/closure cùng commit hoặc rollback.
- Không cho generic transition/batch vào terminal hoặc đi từ terminal để bỏ qua reopen. ADMIN không tự có quyền PM dự án. Project archive khóa write. Endpoint đọc không mở dữ liệu sang dự án khác.
- DTO Bean Validation: số dương, tối đa 100 mục, actual result 8.000 ký tự, reason 1.000; list phần tử null/trùng/thiếu/ngoài phạm vi bị từ chối. SQL nhập liệu dùng bind parameters; tìm kiếm LIKE escape ký tự đặc biệt.
- React hiển thị text, không render HTML từ kết quả/chứng cứ. CSRF trên mutation, cùng session HttpOnly hiện có. Retry giữ draft/key; 409 cần tải bản hiện hành để đối chiếu. Response cũ bị bỏ khi đổi context.
- Evidence thuộc đúng bug/project; FK và service bảo vệ file đã dùng làm căn cứ. Không thay chính sách upload S06; chưa có antivirus production.
- Quét mẫu private key/token trong mã S07 không phát hiện; backup/target/coverage được Git ignore. Không đưa credential vào report. `git diff --check` PASS, chỉ cảnh báo LF→CRLF của repo Windows.
- Review phát hiện cảnh báo otherOpenBugs chỉ xét nguồn NG, thiếu các run mới PM đưa vào scope; đã sửa và thêm regression. Bảo toàn lịch sử khi bản sửa thay đổi và không đóng các bug khác.
